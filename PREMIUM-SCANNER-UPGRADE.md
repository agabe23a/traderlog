# TRADERS LOG 4.0 — Premium Scanner Upgrade

## Included
- Supplied TRADERS LOG gold/green globe logo installed as the primary application logo.
- Favicon and Apple touch icons added so the logo appears in the browser tab/bookmark/app icon.
- Scanner redesigned as a premium command-center interface with:
  - multi-asset universe controls
  - timeframe command chips
  - minimum confluence score
  - BUY/SELL/WAIT and confidence filters
  - sortable ranked opportunity field
  - animated radar telemetry
  - live/session/currency-strength side panels
  - transparent support/resistance, CRT, RSI, ADX, ATR, MACD, invalidation and trade-context fields
  - auto-rescan option
  - mobile-first responsive layout
- Scanner service extended with EMA20/EMA50, market-structure context and volume participation context when volume is available.
- Existing API routes and journal/portfolio/watchlist functionality are retained.

## Data policy
The scanner displays provider-supplied or cached data only. Missing market data remains unavailable rather than being fabricated. Scanner scores are analytical confluence scores, not probabilities or guarantees of profit.
